# STARTWISE — Site corporate (maison-mère)

Projet **indépendant** : site vitrine de **STARTWISE S.à r.l.**, la société qui
porte plusieurs produits. Aucun lien avec les dépôts des produits (LETZSETUP /
setup-app, Ownset / pec-app) — dépôt, déploiement et domaine propres.

## Objectif
- **Crédibilité / confiance** : une vraie présence corporate quand clients,
  partenaires (banques, notaire) ou prospects cherchent « STARTWISE ».
- **Cross-selling** : hub reliant les produits du groupe.
- **About us** : expliquer qui est STARTWISE et ce que fait le groupe.

## Modèle de marque
« House of brands » : STARTWISE = couche groupe ; chaque produit garde son nom,
son site et son SEO propres. Le site STARTWISE ne cannibalise pas le SEO des
produits (domaine séparé, ex. startwise.lu).

- **LETZSETUP** — création de sociétés au Luxembourg (letzsetup.com)

  cross-sell naturel depuis LETZSETUP (toute société créée a besoin d'une compta).
